This project is a browser extension that copies the latest “bearer” token from the active tab to the clipboard.

# to test it
```
npm run dev
```

# to build and generate 

for chrome
```
npm run build
npx wxt zip
```

for Firefox
```
npm run build:firefox
npx wxt zip -b firefox
```

these zip commands generate two files
```
./.output/token-extractor-1.0.0-firefox.zip
./.output/token-extractor-1.0.0-chrome.zip

```

# To install it 

## in firefox

Open Firefox and type  into the address bar.
```
about:debugging#/runtime/this-firefox

```

Click the “Load Temporary Add-on...” button.

In the selection window, select the Firefox .zip file directly

## in chrome

Chrome does not allow the direct installation of “raw” .zip files in developer mode (you must use either an extracted folder or a .crx file).

You don't even need the ZIP file: just use the .output/chrome-mv3/ folder generated by the build command.

Open Google Chrome and type chrome://extensions into the address bar.

Enable Developer Mode (the toggle switch in the top-right corner of the page).

Click the “Load unpacked extension” button (top-left).

Select the .output/chrome-mv3/ folder from your project.
